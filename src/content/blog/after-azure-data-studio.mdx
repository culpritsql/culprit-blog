Microsoft retired Azure Data Studio on February 28, 2026. For years it was my default recommendation whenever someone worked with SQL Server or Azure SQL on a Mac and didn't want to keep a Windows VM around just for SSMS.

## Three gaps that kept slowing me down

Once Azure Data Studio went away, the friction showed up in performance debugging rather than basic querying:

- **Offline `.sqlplan` and `.xdl` files on macOS.** Someone drops a 2 MB `.sqlplan` or an Extended Events `.xdl` deadlock file into Slack or Jira. Reading nested `<RelOp>` XML in a text buffer is painful, and uploading production query plans to a public pastebin is usually blocked by security policy.
- **Tab-flipping to compare two plans.** After adding an `INCLUDE` column or removing a join hint, staring at two big trees in separate tabs makes it easy to miss why one plan is faster or whether a compiled parameter value skewed row estimates.
- **Different tools for every engine.** Most backend teams I work with touch Azure SQL in one service, PostgreSQL in the next, and SQLite in local tests. Learning a separate visualizer per database wastes time when you just want to see which operator burned the I/O.

To fix this for myself, we extracted the parser, plan differ, and deadlock analyzer from [Culprit SQL Studio](https://culpritsql.com) into standalone WebAssembly packages.

## Reading `.xdl` deadlock cycles without SSMS

Deadlock XML captures had the same problem outside Windows. All the evidence is inside the `.xdl` file (`<victim-list>`, `<inputbuf>`, `hobtid` key locks, hold vs wait modes), but reconstructing the cycle by hand during an outage is error-prone.

## Coding agents via MCP

If you use Claude Code, Cursor, or Codex, two commands wire your saved connections into the agent without exposing raw passwords:

```sh
claude mcp add culprit -- culprit mcp
culprit agent init --connection shop
```

From there, the agent can inspect Query Store regressions, pull execution plans, or test a proposed PostgreSQL index via HypoPG (`--with-index`) while read-only guardrails stay enforced locally.
